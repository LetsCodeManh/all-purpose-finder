# Revise completed work

Revisiting a decision is normal. Do not rewind or delete the last valid result.

1. Read the current `MEMORY.md` and keep its stable `status`.
2. Identify the smallest change: session definition, source, criterion, occasion,
   question, refresh, or new output.
3. Show only that change and repeat its gate:
   - source change → `workflows/01-sources/revise.md`, Gate 2
   - criteria change → `workflows/02-criteria/revise.md`, Gate 3
4. A new criterion needing a new source goes through Gate 2 first.
5. After approval, update the stored file and rerun only affected work.

A slug or one-subject/many-candidates change repeats Gate 1. Explain which stored
files it would invalidate and stop before moving or rewriting anything. Prefer a
new session when the core topic or shape has changed; it preserves the old work.

Until a replacement run publishes, call the existing artifact **Previous
Results**. Do not broaden `results.md` beyond its approved sources and criteria.

A refresh without a source or criteria change needs no new gate; route to
`workflows/03-run/README.md`. Reopening or adding an output routes to
`workflows/04-next-steps/README.md`.
