# Session router

Every Finder request enters here.

1. If no slug or topic was given, read `open.md` → **Bare request**.
2. If a slug was given, read `open.md` → **Named session**.
3. If a new topic was described, read `new.md`.
4. If an existing session is being changed, read `revise.md` and the workflow
   folder for the thing being changed.

Do not create anything until Gate 1 is approved. For an existing session, read
`sessions/<slug>/MEMORY.md` before choosing another workflow.

Rules: `AGENTS.md`.
