# Criteria router

Use the `02 — criteria` section of `examples/<shape>.md`.

- No approved `criteria.md`: read `initial.md`.
- Changing approved criteria: read `revise.md`.
- Changing approved sources instead: read `workflows/00-session/revise.md` first.

Input for an initial pass: approved `sources.md`, `status: criteria`. Output after
Gate 3: `criteria.md`, `status: run`, `next: first run`.

Rules: `AGENTS.md`. Format: `sessions/_template/criteria.md` and `CONTRACT.md`.
