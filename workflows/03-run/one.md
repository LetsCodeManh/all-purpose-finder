# Run one subject

Use this only for `cardinality: one`.

There is no candidate set to narrow or compare. Do not create `listings.md`, run a
prefilter, score facts, or invent `new`, `gone`, or dropped-row sections.

Read the approved sources against the approved questions. Write the result in the
`form` and sections defined by the shape's `03 — run` example. For a brief:

- attribute every factual claim to an approved source
- distinguish the subject's claims from independent reporting
- label unanswered questions and conflicting evidence
- state how deeply each source was read
- keep private or purpose-inappropriate information out
- end with the complete run gap report

Update `last checked` only for sources actually read. Keep failures and skipped
sources visible instead of making them look fresh.

Use `Prepared YYYY-MM-DD` in the header and follow the exact machine-readable
requirements in `CONTRACT.md`.

If `selection: artifact`, the complete result becomes Gate 4's input and no
shortlist exists. If an unusual one-subject shape selects rows, follow
`shortlist.md` only when its shape example defines valid row identities.

Finish with `publish.md`.
