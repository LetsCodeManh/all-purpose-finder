# Next Steps router

The published result exists. This workflow decides what, if anything, happens
with it.

- the user asks a question, wants advice, or wants to talk through the result:
  read `discuss.md`.
- `status: next-steps`: read `choose.md`.
- `status: done` and the user wants to return: read `choose.md`.
- an output-name status and the user wants another output: read `choose.md`.
- the user already chose an output: read `make.md`.
- the user wants fresh results instead: use `workflows/03-run/README.md`.
- the user corrects sources or criteria: use `workflows/00-session/revise.md`.

Use the shape's `selection` field and its `04 — Next Steps` example. Choices come
from the actual result and conversation, never from a stored menu.

Rules: `AGENTS.md`.
