# Sources router

Use the `01 — sources` section of `examples/<shape>.md`.

- No approved `sources.md`: read `initial.md`.
- Adding, removing, or rechecking sources later: read `revise.md`.
- A browser or hand check follows the manual-check rules in the selected file;
  it never changes a source's reproducible method.

Input for an initial pass: `status: sources`. Output after Gate 2:
`sources.md`, `status: criteria`, `next: write criteria`.

Rules: `AGENTS.md`. Table format: `sessions/_template/sources.md` and
`CONTRACT.md`.
