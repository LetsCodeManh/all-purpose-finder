# Reusable next steps

This optional folder holds generic procedures for outputs that have already
worked in a real session. It never defines the choices offered at Gate 4.

Run a new output directly from the user's request. Afterwards, ask before writing
its reusable procedure here. Keep every file public and generic: no session facts,
names, personal details, URLs, vendors, or hidden assumptions.

An empty library is normal. Scout and Advisor still support open-ended Next Steps.
